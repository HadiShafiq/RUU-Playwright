Update MOF Profile: test flow

This test changes SIT data. It saves a new draft, deletes branches and uploads documents. Record each run in knowledge/data-change-audit.md. Drafts on this account (KU-28102026-0028 and 0029) have been "Deleted by Contractor" by someone outside the automation, so check Application Status if MOF-001 suddenly creates a new application.

Safety rails in the test

  • ✕Never clicks Declare or Submit
  • ✕Never clicks the top Delete, which deletes the whole application
  • ✕Never goes back to Task List between sections
  • ✕Never creates a new application when one is pending
  • ✓Deletes branches only after checking the selection is exactly "all except SELANGOR"
  • ✓Login from the git-ignored .auth/credentials.xlsx; the password is never logged or committed
