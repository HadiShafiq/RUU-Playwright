Safety rails in the test

  • ✕Never clicks Save, Submit, Declare or the Delete buttons
  • ✕Never answers OK or Yes in a confirmation box
  • ✕Never creates a new application when one is pending
  • ✓Checks "Modified By" before and after to prove nothing was saved
  • ✓Credentials come from the run's environment only, never from files
  • ✓The page object has no methods for saving or deleting
